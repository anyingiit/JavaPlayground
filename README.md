# JavaPlayground

A Java learning playground of hand-written data structure and algorithm exercises — a resizable generic array, a binary max-heap, heap sort and merge sort, each backed by JUnit 5 tests — plus a folder of short standalone snippets exploring core Java language features.

## About The Project

`src/Array/Array.java` is a from-scratch generic array (`Array<E>`) with the usual insert/remove/find operations, and `src/MaxHeap/MaxHeap.java` builds a binary max-heap on top of it. `src/HeapSort/` (ascending and descending) and `src/MergeSort/SortByDESC.java` are two independent sort implementations that do not share code with the heap above, and `src/OrderArray/OrderArray.java` checks whether an array is already sorted ascending or descending. Every one of these except `MaxHeap` has a JUnit 5 test class next to it, and the sort tests also run against a million random integers generated by `src/Random/Random.java`.

`src/Play_22_6_12/` is a separate, unrelated folder: sixteen small files (`P1.java` through `P16.java`), each a short, disconnected snippet exploring one Java language feature — interfaces, abstract classes, method overloading, `try`/`finally` return semantics, autoboxing, anonymous classes. They are scratch notes, not part of the data structures above.

See the [open issues](https://github.com/anyingiit/JavaPlayground/issues) for planned features and known issues.

## Getting Started

### Prerequisites

- A JDK (any recent version; the source uses no version-specific language features)
- No dependencies to fetch: every JUnit 5 jar the tests need is already vendored under `libs/JUnit5/`, since the project has no build tool (no `pom.xml`, no `build.gradle`)

### Installation

```sh
git clone https://github.com/anyingiit/JavaPlayground.git
cd JavaPlayground
javac -d out -cp "libs/JUnit5/*" $(find src -name '*.java')
```

## Usage

There is no application to run — the source is a set of classes and their JUnit 5 tests. Compile everything, including the small test-runner bootstrap under `ci/` (added alongside this README, since the vendored jars do not include a standalone console launcher), and run the suite:

```sh
javac -d out -cp "libs/JUnit5/*" $(find src ci -name '*.java')
java -cp "out:libs/JUnit5/*" RunTests
```

This discovers and runs every `@Test` method under `src/` — currently the `OrderArray`, `HeapSort` and `MergeSort` suites — and exits non-zero if any test fails or none are found.
